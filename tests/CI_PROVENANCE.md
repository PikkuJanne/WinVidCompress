# CI dependency provenance - checked 2026-10-07

This is explicit developer/CI setup, not an application dependency installer. Selected archives are downloaded without credentials to a new isolated runner-temp root, checked against committed accepted-content digests, then inspected/extracted. Digests detect replacement bytes; they do not constitute publisher signing or general supply-chain authentication. Review upstream support/security notices before a separate pin update; never silently fetch latest packages. No dependency binaries are committed or added to the user distribution.

The Gallery publishes package hashes as base64 SHA512; CiDependencies.psd1 stores the decoded lowercase hex digest. Both selected packages publish empty dependency lists. The FFmpeg ZIP's extracted ffmpeg.exe/ffprobe.exe hashes also match the existing tested workstation build and are checked before tests. The PowerShell release tag resolves to source commit `f260eb9c31ec72c5282f98e5ea24d9be4f8d7536` (annotated tag object `fe2f984794c6e67ba4d61722ce4b09256b0ec363`). Exact version download URLs and all digest values live in CiDependencies.psd1.

Both selected actions use Node24; checkout documents runner >=2.327.1 ([compatibility](https://github.com/actions/checkout/blob/v7.0.1/README.md)). The observed current runner release was [2.338.0](https://github.com/actions/runner/releases/tag/v2.338.0); actual hosted image/OS versions are saved in sanitized results. Microsoft's [support lifecycle](https://learn.microsoft.com/en-us/powershell/scripting/install/powershell-support-lifecycle) lists 7.6 LTS through 2028-11-14 and requires current servicing updates. Pin maintenance must review that policy; the existing developer minimum7.4 is not a guarantee that every older patch remains supported.

Workflow permissions/events follow [GitHub's secure-use guidance](https://docs.github.com/en/actions/reference/security/secure-use): full action commit pins, read-only repository token, no persistent checkout credentials or secrets, no privileged PR-target checkout, and event values passed through validated environment/argument boundaries. Only the explicit sanitized summary path is uploaded; no raw logs, media, config, module tree or private fixture paths. Action references are pinned by immutable Git commits; version ZIP/package URLs can be replaced upstream and must continue matching the recorded hashes.
