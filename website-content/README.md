# WinVidCompress product content

This is locally prepared static content for a future tools website. `product.json` follows `product.schema.json` (schema version 1). It is a draft, with all published version, date, release URL, download URL and ZIP checksum fields null. The separate candidate fields describe an unpublished source snapshot and its script hashes; those are not download checksums. No site is deployed by this folder.

WinVidCompress makes consistent H.264/AAC viewing copies on a Windows computer. Drag files or folders onto the BAT launcher, or use its four-item menu. Batches run sequentially and outputs have safe collision names. Originals and existing finals remain in place. Keep originals: conversion is lossy, and a valid output can grow.

The fixed profile is libx264, veryfast, CRF 22; AAC 160k when audio is present; 8-bit yuv420p SDR MP4 with +faststart. It does not crop or upscale. Oriented height is capped at 1080 with even dimensions; width is not capped at 1920. Detected HDR is refused. The first real video stream and one selected audio stream are encoded; other streams are omitted and reported. Compatible source metadata can remain.

Use Windows PowerShell 5.1 through the BAT launcher or a supported stable PowerShell 7 for direct commands. Supply FFmpeg and FFprobe separately, using a Windows provider linked by [FFmpeg](https://ffmpeg.org/download.html) and its integrity guidance. PATH copies take precedence over adjacent binaries. The tool does not download dependencies. Follow [setup and first-copy instructions](../README.md), [option/media reference](../docs/user/REFERENCE.md) and [troubleshooting](../docs/user/TROUBLESHOOTING.md).

Processing runs on the user's device without application uploads, accounts or telemetry. Explicit UNC paths can access network shares. Config, logs, manifests and outputs can contain private paths and metadata; review diagnostics before sharing. Project code retains the [Unlicense](../LICENSE); separate dependencies have [build-dependent terms](../THIRD_PARTY_NOTICES.md). This candidate is unsigned. A checksum does not authenticate the publisher or certify safety.

Use [repository issues](https://github.com/PikkuJanne/WinVidCompress/issues) for sanitized synthetic bug reports and the [security policy](../SECURITY.md) for security concerns. [Changelog](../CHANGELOG.md) and [verification limits](../docs/user/VERIFICATION.md) describe the current implementation and evidence.
