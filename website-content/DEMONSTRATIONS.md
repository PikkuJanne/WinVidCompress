To reproduce a capture, create a new disposable demo folder with the two scripts and separately verified FFmpeg/FFprobe executables. In a separate process set APPDATA to a new demo directory, unset FFREPORT, and use a demo-only `WinVidCompress/config.json` containing its existing public OutputDir. Launch the real BAT or PS1 menu, capture just that window, and inspect every pixel for personal paths, unrelated windows, credentials and private footage before saving. Do not select private inputs. Record host version, source commit, script hashes, actual command, capture method, dimensions and image SHA-256. Keep raw diagnostics and dependencies local.

These warm-cache timings include the job's probe/encode/validation/publication/cleanup, exclude fixture generation and review, and are not speed promises. Faststart relocation is included in encode/mux time and was not separately measured.
