# Genuine demonstrations

The menu image must be an actual application-window capture, not a recreated console, mock interface or generated picture. Its manifest in `product.json` identifies the exact source, capture method, checksum and any redaction. A public demo output directory and isolated APPDATA keep personal preferences and paths out of the image. The copied PS1/BAT bytes are the unchanged tracked scripts from main `b2582bd24b7efaa896b51d468c3679ee83bcb909`.

To reproduce a capture, create a new disposable demo folder with the two scripts and separately verified FFmpeg/FFprobe executables. In a separate process set APPDATA to a new demo directory, unset FFREPORT, and use a demo-only `WinVidCompress/config.json` containing its existing public OutputDir. Launch the real BAT or PS1 menu, capture just that window, and inspect every pixel for personal paths, unrelated windows, credentials and private footage before saving. Do not select private inputs. Record host version, source commit, script hashes, actual command, capture method, dimensions and image SHA-256. Keep raw diagnostics and dependencies local.

The [synthetic measurement](examples/synthetic-default.json) comes from three successful runs of the existing `tools/benchmark.ps1` on the same clean main source, with `-Repeats 3 -SyntheticSeconds 4`, verified native executables, isolated APPDATA/output and no candidate preset or CRF override. The report includes exact fixture-generation and encoder tokens with path placeholders, actual host/tool versions, hashes, bytes and stage timings. The source is a four-second 320x240, 24 fps test pattern with 440 Hz/48 kHz tone, stored as FFV1/PCM.

Each run measured **1,134,269 input bytes** and **235,009 output bytes**, a **79.281% reduction** for this synthetic lossless source. Total job time was **0.443-0.800 seconds**, median **0.508 seconds**, on the recorded workstation. These warm-cache timings include the job's probe/encode/validation/publication/cleanup, exclude fixture generation and review, and are not speed promises. Faststart relocation is included in encode/mux time and was not separately measured.

This source is not a typical already-compressed interview. Results depend on source, settings, hardware and build; valid outputs can grow. No face, readable interview text, speech-sync or representative compression-quality verdict follows from the pattern and tone. Playback remains **NotRun** in this new example. Structural validation and separate full-decode checks do not establish full visual/audio integrity. Earlier owner playback evidence retains its original scope.
